# Answer keys — sources

Generated 2026-10-19 from `answer-keys.json` (schema v1). 85 plan keys and 22 real-world standards.

## Policy: facts only

- Each key records **facts**: overall size, part count, key counts (drawers, shelves, legs, slats and so on), primary stock and hardware kinds.
- No plan text, steps, drawings or photos were copied. The prompt in each key is our own wording.
- Every key links to its free source plan so a reviewer can check it.

## How the numbers were derived

- **stated**: the plan prints the overall size in text.
- **derived**: the size was worked out from the plan's own cut list. For example, the width is the shelf length plus two side thicknesses, using actual lumber sizes (a 2×4 is 1½×3½). These keys are `medium` or `low` confidence.
- **standard**: the plan is sized to a mattress standard, so the size follows the standards table below.
- Part count is the sum of the cut-list quantities. Hardware is counted as hardware, and plywood sheets count as their cut parts. Treat part count as a soft signal, because Yard may count a glue-up as one part.
- Tolerances get wider as confidence drops: high ±1″, medium ±2″, low ±4″. See the `scoring` block in the JSON.
